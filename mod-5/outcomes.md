# Module Description

This module introduces you to some basic methods for working with data in a digital context, from collection to analysis to ethical use and presentation. Portions of the module are reproduced with little or no modification from the [CUNY DHRI-Curriculum GitHub repository "Data Literacies,"](https://github.com/DHRI-Curriculum/data-literacies) licensed [CC-BY-SA](http://creativecommons.org/licenses/by-sa/4.0/).

# Learning Outcomes
At the completion of this module you should

1. Know the stages of data analysis
2. Understand the difference between proprietary and open data formats
3. Be familiar with the specific requirements of "high quality data"
4. Understand some basic ethical issues around working with different types of data and analysis
